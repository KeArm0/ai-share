2.（3）完整案例

UI 优化：按工作流完整跑通

输入需求（生成规范 + 原型）
先不要直接改业务代码。请基于产品配置系统现有功能，输出 UI 设计规范 + 可点原型。

边界：功能语义不变；登录 / 列表 API 与路由不变；只调整展示与交互层级。
主题色：主色 #00246e；语义色用暗调；不使用蓝紫渐变。
布局原则：一屏一个白色承载面；不做卡片套卡片；控件圆角 2px、承载面 4px；阴影仅用于浮层。
页面范围：登录页、用户管理、类目管理、价格管理等核心页。
登录页：左右分栏（左品牌区 / 右表单），约 960×520；取消大圆角重阴影，改为 4px + 1px 边框。
列表页：去掉多余标题卡；操作列收敛为「编辑 + 更多」；表格用主题色 hover / 选中态。
